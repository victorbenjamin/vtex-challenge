# Planos

Um arquivo por plano: `NNN-slug.md`, numerado em ordem de criação (`001-...`, `002-...`).

Cada plano deve ter:
- **Status:** `proposto`, `aprovado`, `em andamento`, `concluído` ou `abandonado`, com data.
- **Objetivo** e **contexto**, com links para a análise em `docs/analysis/` que o fundamenta.
- **Decisões**, com as alternativas descartadas e o motivo.
- **Passos**, como checklist.
- **Desvios**, registrando o que mudou durante a execução e por quê.

Planos concluídos ou abandonados continuam aqui, porque fazem parte do histórico de decisões.
